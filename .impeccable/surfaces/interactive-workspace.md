# Interactive document workspace proposal

Mode: Operate. Target: apps/web/src/preview/WorkspacePreview.tsx.

Preserve the existing Quiet Star Chart tokens. A student's documents and questions are the first things to understand. The orbit is a way to choose sources; the graph is a second, connected view. Keep the central reading/composer area compact enough to leave documents usable. A right inspector narrows the canvas on desktop and becomes a full-height sheet on mobile.

The signature moment is one visible uploaded document moving from a composer attachment through a real processing loop to its retained orbital slot. The loop waits for actual terminal success. Batch imports use a single coordinated interface and preserve the conversation. Failure retains the filename, stops motion and offers recovery.

Phase 1 produces a visibly labelled sample-state viewer and editable Figma frames, not a replacement live application. Preview states: empty, processing, document orbit, cited answer and source inspector. Questions skipped: the user supplied the audience, palette, behavior, stack, scope and explicit Phase 1 stopping point. The only necessary external choice was the Figma team, selected as stanleylur’s team.

Source truth and mapping are in docs/redesign/phase-1-plan.md. No new dependency or public deployment is part of this checkpoint.
