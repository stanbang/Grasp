# Portfolio About snippet

I built Grasp so students can ask questions about their own notes and open the passage behind an answer. It uses retrieval-augmented generation to find relevant text before a language model answers. The same passages connect ideas on a concept map and provide sources for mastery quizzes. The recorded showcase lets visitors explore that source trail using bundled notes. [Grasp on GitHub](https://github.com/stanbang/Grasp)
