# Grasp showcase assets

The SVG diagrams are original artwork based on [the evidence audit](../facts.md). Chrome rendered the PNG versions of those diagrams and the social preview from their SVG sources.

The logo links stars into a G. `logo.svg` works on light and dark surfaces. `logo-mono.svg` takes the surrounding color when embedded inline. `favicon.svg` puts the accent mark on the workspace background. `social-preview.png` is 1280 × 640.

`showcase.gif` was captured from the local preview using the bundled Computer networks trace. It shows the stage replay, a recorded answer and the highlighted source quote.

The project author supplied [grasp-architecture.png](grasp-architecture.png) for the course walkthrough. The [RAG design notes](../rag-design.md) explain how vector retrieval and the concept graph use stored source chunks.
