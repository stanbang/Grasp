# Grasp showcase assets

The SVG diagrams are original local artwork based on [the evidence audit](../facts.md). Their PNGs were rendered from the SVGs in Chrome. The social preview follows the same process. Figma's quota blocked editing and export from the [Grasp draft](https://www.figma.com/design/3rtdi0qiFA8f6ct5MlOp76).

The logo links stars into a G. `logo.svg` works on light and dark surfaces. `logo-mono.svg` takes the surrounding color when embedded inline. `favicon.svg` puts the accent mark on the workspace background. `social-preview.png` is 1280 × 640.
