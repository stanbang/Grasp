### Earlier portfolio runs

Each row is a recorded retrieval experiment with its own embedding mode. Hit@1 and Hit@3 count the fraction of cases with evidence in the indicated prefix. MRR@3 is the mean reciprocal rank of the first match, with zero for a miss. The runner times warm retrieval including the query embedding call and, where applicable, term sorting. It excludes indexing, generated answers and browser time. Context size is the mean character count of the first three passages. It is a proxy for prompt size rather than a token count.

## Proposed measurements and cost

Provider cost and end-to-end latency are **not measured yet**. Run the local checks first. The paid figures below are proposed caps for planning, not measured bills or commitments. They use Google's standard paid rates of USD 0.15 per million embedding input tokens for [Gemini Embedding](https://aistudio.google.com/docs/pricing#gemini-embedding) and USD 0.25 per million text input tokens and USD 1.50 per million output tokens for [Gemini 3.1 Flash-Lite](https://aistudio.google.com/docs/pricing#gemini-3.1-flash-lite). Confirm rates and enforce token caps before an approved run. No provider calls were made for this audit.
