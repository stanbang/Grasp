# Separate provider use from the recorded showcase

**Status:** Implemented.

Keep provider keys in the local workspace. Record the same ingestion function using the mock adapter and public samples. The browser receives the captured evidence and projected points. Suggested questions reuse captured excerpts, and other questions use a local term match. The drop listener accepts only bundled IDs and ignores private file data.

This gives visitors the source trail without depending on an API or a key. The demonstration does not measure live generation quality. Revisit a public live service only after measuring access controls, capacity and cost. [Trace and drop verification](../facts.md#what-the-workspace-does)
