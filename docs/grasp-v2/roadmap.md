## Acceptance criteria

Numbers below are proposed gates for review. Record actual outcomes against them. The [baseline](baseline.md#baseline-verification) documents the Phase 0 runs.

| ID | Verification and pass threshold |
| --- | --- |
| C1 · Camera | Unit-test client/world round trips at zoom 0.25, 0.5, 1, 2 and 3 with offsets and pane insets. Browser tests at 1440 × 900 and 1280 × 720 hold the zoom anchor within 2 CSS pixels. Fit and selection fit put nonempty bounds in the usable viewport with at least 24 CSS pixels of padding. Test a wheel mouse and trackpad or record the missing physical device. |
| C2 · Editing | Drag, resize, Shift multi-select, marquee, grouping and ungrouping preserve object and canonical IDs. Reparenting keeps apparent position within 2 CSS pixels. Pointer cancellation leaves the previous revision intact. Keyboard selects and moves an object without dragging. One undo/redo reverses/reapplies each finished transaction. |
| C3 · Graph mapping | Import the same fixture twice, switch 2D → 3D → 2D, and verify a 1:1 canonical reference per mapped instance, the same relation endpoints and unchanged source IDs. Two visual instances can deliberately refer to one concept. The default 2D entry does not request the 3D chunk. |
| C4 · Presentation | Seven reachable frames, no dead source links in the default sequence, keys and buttons navigate the same order. A visit to Knowledge and return restores board, frame and camera. Escape exits with focus restored. Reduced motion settles on the target without animation. Presenter notes are outside the audience view. |
| C5 · Import and provenance | Exercise PDF, Markdown, UTF-8 text and a mixed success/failure folder. Replayed SSE resumes after a cursor without duplicates. For every tested chunk and citation, verify document, one-based page, Unicode code-point span and exact substring. Observe duplicate identity, partial failure, replacement, removal and re-indexing against current behavior. |
| C6 · Persistence and isolation | Load an existing database without data loss. Reload after moving a card, adding a note and creating a frame. Verify a stale revision returns `409`, retrying one mutation does not duplicate it and interrupted saves preserve a recoverable draft. Replace or remove a source, then verify stale bindings have an explicit unavailable state. 3D geometry never persists. |
| C7 · Q&A, mastery and scope | Scoped fixture questions produce zero out-of-scope citations or graph highlights. Include a saved follow-up and an unsupported response with zero citations. Three quiz answers remain hidden until grading, and two correct answers mark the assessed nodes mastered. User notes never enter canonical retrieval by default. |
| C8 · Accessibility | At 390 × 844, 1280 × 720 and 1920 × 1080, reach all active actions without page overflow. Test keyboard-only board/frame navigation, names, focus order, dismissal and focus return. Test 200% browser zoom. Target WCAG AA text contrast and 3:1 for focus/interactive boundaries. Use reduced motion and a list alternative for navigating or selecting objects. |
| C9 · Pipeline evidence | Use actual stage IDs/order and show each measured time only if recorded. Compare the final displayed citation list with the chat result and validate exact quotes; show rank in resolved order, zero fabricated scores and zero provider secrets in payloads. Disconnect/reconnect ingestion and simulate one provider error in an isolated environment. Live walkthrough stays navigable after failure. |
| C10 · AI operations | Test unknown types, bounding limits, invalid IDs, cross-board references, stale revision, invalid evidence and unauthorised updates. All reject with zero persisted mutations. Accept a valid multi-op proposal, then undo it in one transaction and verify exact pre-edit board state and unchanged semantic graph. |
| C11 · Offline and reset | With provider credentials absent and provider traffic blocked, load Engineering and complete the five-minute story using local mock processing or explicitly marked replay. Verify zero external provider calls. Reset through confirmation and compare study database hashes or scoped records before/after to prove isolation. |
| C12 · Performance | Profile a named desktop/Chrome environment and a 250-object/400-edge board at 1440 × 900. In three 10-second pan/drag/zoom runs, target p95 frame interval ≤ 33 ms and p95 input-to-visible update ≤ 80 ms. Report traces, element counts, device, browser, zoom range and misses. Treat targets as release gates to tune with evidence. |
| C13 · Regression and delivery | Contract drift check, Python and Node tests, strict TypeScript and production build pass. Desktop smoke includes complete use of both workspaces, grounded questions and recorded fallback. Projector and responsive review include dark/light, keyboard and motion. Run `npx impeccable detect apps/web/src` and record remaining findings. Time one complete presentation run, targeting 4:30–5:30. |

## Risks and open choices

- Scope and rendering quality have first priority. Test camera and custom card accessibility early. Use lazy loading, memoized mapping and visibility filtering when measurements justify them. Keep routing, layout, persistence and presentation independent of 3D.
- Native Enso controls were outside the observed public surface. Treat advanced freehand, camera timing and inspector behavior as GRASP design choices verified in Phase 1 or Phase 5, as applicable.
- Added pipeline instrumentation needs an explicit data review. With coarse baseline events, a stage can remain combined or unavailable. Retrieval rank is useful without a similarity score.
- The app remains local and single-owner. Keep study, disposable demo and static replay data isolated from each other. Live checks, hosting, licenses outside the authorized stack and publication remain separate approval decisions.
- Impeccable's live critique, polish and final audit concern the rendered future interface. The Phase 0 design is a written shape proposal. The Humanizer skill could not be located in the configured skill paths. Prose was reviewed directly.
