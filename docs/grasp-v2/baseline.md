## Implementation inventory

The baseline uses React 18.3, TypeScript strict mode, Vite, Tailwind, Zustand, Lucide, Three.js and react-force-graph-3d. The Python 3.11 service uses FastAPI, Pydantic v2, SQLModel/SQLite, local Chroma, LangChain with OpenAI and Gemini adapters, and an optional Poppler/Tesseract OCR path. Vite proxies `/api` in development. Production mounts the API and serves the built frontend from the same origin. Chrome opened the local workspace on loopback with the **Offline mock** indicator and empty import state. After the file-chooser automation session expired, the built-in sample opened the composer. Asking “What is retrieval practice?” exposed two page-one source buttons. The first opened the corresponding source dialog. Chrome also opened the recorded technical guide at `/showcase/?view=guide` and returned to the replay index using **Back to replay**.

The full multipart upload flow was verified over the same Vite/FastAPI HTTP boundary with a public repository note and an isolated data directory. The sample reached `done` with 3 chunks, 9 nodes and 8 edges. SSE emitted four status, nine node, eight edge and one complete event. Replay matched byte for byte. The scoped question yielded two exact page-one citations and eight referenced nodes. A repeat upload returned the same document ID. The unsupported question had zero citations, and both turns were saved. SQLite and Chroma passed loopback health checks. Native OCR, real device drag and paid providers were outside the fresh smoke.

New offline evaluations produced the one-note checkpoint at Hit@5 1.000 / MRR 0.950 (20 labeled questions, 3 chunks).
```powershell
$env:MOCK_LLM='1'
$env:DATA_DIR='work/grasp-v2-phase0/recheck'
$env:ACCESS_TOKEN=''
python scripts/check.py
npm run build
python scripts/dev.py
```

Open the workspace at the launcher URL and the recorded demo at `/showcase/`. The Vite development default is 5173 and the API default is 8000. Use `$env:API_PORT` and `$env:WEB_PORT` to choose free loopback ports. Real study data is unnecessary for this smoke.
