# Memory and learning

These short notes are original demonstration material for this project. They are not a research review.

## Working memory

Working memory holds information briefly while a person uses it. Keeping several unfamiliar ideas active at once can make a task difficult. Breaking a task into smaller steps can reduce that demand.

## Long-term memory

Long-term memory stores knowledge beyond the current task. A useful concept is easier to revisit when it has a clear name, a short explanation and an example. New knowledge can connect to something the learner already knows.

## Retrieval practice

Retrieval practice means trying to recall an idea before looking at the answer. A learner can write a question, close the notes and explain the answer from memory. Checking the source afterward helps identify missing or mistaken details.

## Spaced practice

Spaced practice separates study sessions over time. The learner returns to an idea after a gap instead of repeating it only within one session. A later session can begin with retrieval practice.

## Feedback

Feedback compares a response with the source material. Specific feedback identifies what was correct and which part needs revision. A learner can use that information to choose the next concept to study.

## Concept maps

A concept map represents ideas as nodes and relationships as labelled connections. One node can link to several passages or documents. A connection can show that one idea supports, limits or provides an example of another idea.

## Checking understanding

Reading a passage and answering a question are different activities. In this app, exploring a concept records that it was visited. Mastery requires a separate quiz. The mastery state does not prove long-term retention.

## Source references

An exact citation identifies a document, a page and the passage used in an answer. Character offsets identify where a chunk begins and ends in the extracted page text. For Markdown and text notes, the whole document is page 1. End offsets are exclusive.
